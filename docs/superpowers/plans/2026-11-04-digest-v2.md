# Tech Digest v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the 10:00 digest layout with a summary table plus a no-reply list, and add a 14:00 stalled-conversations report.

**Architecture:** The existing fetch → normalise → build → post pipeline stays. New pure `metrics.py` computes both reports from tasks plus comments. `digest.py` is rewritten into `build_daily` / `build_stalled`. The Slack client gains an email lookup and the table fallback. `main.py` gets `--report daily|stalled`.

**Tech Stack:** Python 3.12, requests, PyYAML, tzdata, pytest; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-04-digest-v2-design.md` (schedule changed after approval to 10:00 and 14:00 IST).

## Global Constraints
- Scope: open tasks in both projects, created by `config.asana.support_team` (ID → name). Product & Tech means anyone not in support_team.
- A comment is a story with `resource_subtype == "comment_added"`.
- Thresholds: open > 96h (metric 2), > 48h with no Product & Tech comment ever (metric 4), last comment > 24h with at least one Product & Tech comment (stalled).
- Lists are grouped by assignee: biggest group first, Unassigned last, up to 10 per group then "+N more", oldest first inside each group.
- Cron: daily `27 4 * * *` (09:57 IST), stalled `27 8 * * *` (13:57 IST).
- Tags: Slack `users.lookupByEmail`, cached per run. If a lookup fails, show `*Name*`. A tag never fails a post.
- Table: a Slack `table` block. On `invalid_blocks`, resend once with a monospace table in a section.
- Nothing is posted unless the full message builds. A comment-fetch failure fails the run.

## Review Focus
1. A task with comments only from support members counts as "no Product & Tech reply".
2. A boundary age of exactly 48h or 96h is not counted (strict >).
3. An assignee with no email, or an email not found in Slack, shows a bold name and the post still goes out.
4. Stories pagination over 100 comments follows every page.
5. The stalled report with nothing stalled still posts the "✅" line.
